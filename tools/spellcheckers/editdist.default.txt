## Transition pair specifications + weight:
##
## Both directions of a confusable pair have to be listed. editdist.py
## documents that a single FROM/TO line also sets TO -> FROM at the same
## weight, but that back-fill lives in the ATT code path only; --regex, which
## is what this file is built with, reads the specified pairs verbatim and
## leaves everything else at DEFAULT_WEIGHT. An unlisted direction is not
## symmetric, it is 10.
##
## n -> ŋ has no counterpart on purpose: ŋ -> n does not occur once in the
## typo corpus, and ŋ -> ñ would license suggestions spelled with ñ, which is
## not part of the orthography. ñ -> ŋ stays at 0 - that is normalisation of
## a substitute letter, not a typo.
